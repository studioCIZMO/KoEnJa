KoEnJa 0.1.0 (테스트판 / テスト版)
==================================

■ 한국어

KoEnJa는 한국어·영어·일본어를 하나의 키보드로 입력하는 Windows 입력기입니다.
언어를 바꾸지 않고 그냥 치면 됩니다: 두벌식 자판으로 한국어(dkssud → 안녕), 로마자로 일본어
(konnichiha → こんにちは), 영어는 그대로. 단어마다 어느 언어인지 자동으로 판단합니다.

설치
  1. KoEnJa-Setup-0.1.0.exe 를 실행합니다.
  2. 아직 서명하지 않은 테스트판이라 "Windows의 PC 보호" 화면이 나옵니다.
     "추가 정보" → "실행" 을 누르세요. 이어서 관리자 권한 확인에서 "예".
  3. 마지막 화면에서 "KoEnJa 설정 열기" 를 체크한 채 마침 → 키보드 종류, 쓰는 언어, 전환 키를 고릅니다.
     (나중에 시작 메뉴의 "KoEnJa 설정" 에서 바꿀 수 있습니다.)
  * 64비트 Windows 10/11 (x64) 전용입니다. ARM64 Windows는 아직 지원하지 않습니다.

KoEnJa로 바꾸기
  작업 표시줄 오른쪽의 언어 표시(한/あ/ENG)를 눌러 "KoEnJa" 를 고르거나, Win+Space 로 바꿉니다.
  한국어·일본어 입력 목록에 KoEnJa가 추가됩니다 (둘 다 없으면 한국어를 추가합니다).

키
  - 전환 키 (기본: 한국어 키보드는 오른쪽 Alt = 한/영, 일본어 키보드는 無変換)
      입력 중: 지금 단어를 다음 언어로 바꿉니다.
      입력 중이 아닐 때: 우선 언어 바꾸기 (한국어 우선 ↔ 日本語優先, 세 언어를 다 쓸 때),
                         두 언어만 쓸 때는 KoEnJa 켜기/끄기 (끄면 그냥 영어).
  - Space / 変換: 일본어 한자 변환 (한 번 더 누르면 후보 목록, 1–9로 고르기, Enter로 확정, Esc로 취소)
  - 半角/全角 (일본어 키보드): KoEnJa 켜기/끄기
  - F6/F7: 히라가나/가타카나, F8–F10: 반각 가타카나 / 전각·반각 로마자

삭제
  설정 → 앱 → 설치된 앱 → "KoEnJa" → 제거.
  입력 목록에서도 빠집니다. 쓰는 중인 앱이 있으면 일부 파일은 다시 시작할 때 지워집니다.
  설정과 학습한 단어(%LOCALAPPDATA%\KoEnJa)는 남겨 둡니다. 필요 없으면 그 폴더를 지워도 됩니다.

개인정보
  입력한 내용은 PC 밖으로 나가지 않습니다. 인터넷에 연결하지 않고, 아무것도 보내지 않습니다.


■ 日本語

KoEnJa は韓国語・英語・日本語を一つのキーボードで入力できる Windows の入力方式 (IME) です。
言語を切り替えずにそのまま打てます: 韓国語は2ボル式配列 (dkssud → 안녕)、日本語はローマ字
(konnichiha → こんにちは)、英語はそのまま。単語ごとにどの言語かを自動で判断します。

インストール
  1. KoEnJa-Setup-0.1.0.exe を実行します。
  2. まだ署名していないテスト版のため「Windows によって PC が保護されました」と表示されます。
     「詳細情報」→「実行」を押してください。続く管理者の確認で「はい」。
  3. 最後の画面で「KoEnJa の設定を開く」にチェックしたまま完了 → キーボードの種類、使う言語、
     切り替えキーを選びます。(あとでスタートメニューの「KoEnJa 설정」から変えられます。)
  * 64 ビット版 Windows 10/11 (x64) 専用です。ARM64 版 Windows にはまだ対応していません。

KoEnJa に切り替える
  タスクバー右側の言語表示 (あ/한/ENG) をクリックして「KoEnJa」を選ぶか、Win+Space で切り替えます。
  日本語・韓国語の入力方式の一覧に KoEnJa が追加されます (どちらもなければ韓国語を追加します)。

キー
  - 切り替えキー (標準: 日本語キーボードは 無変換、韓国語キーボードは右 Alt)
      入力中: いま打っている単語を次の言語に変えます。
      入力していないとき: 優先言語の切り替え (日本語優先 ↔ 한국어 우선、3言語とも使う場合)、
                          2言語だけのときは KoEnJa のオン/オフ (オフは英語そのまま)。
  - Space / 変換: 漢字変換 (もう一度で候補一覧、1–9 で選択、Enter で確定、Esc で戻る)
  - 半角/全角 (日本語キーボード): KoEnJa のオン/オフ
  - F6/F7: ひらがな/カタカナ、F8–F10: 半角カタカナ / 全角・半角英字

アンインストール
  設定 → アプリ → インストールされているアプリ → 「KoEnJa」→ アンインストール。
  入力方式の一覧からも外れます。使用中のアプリがあれば、一部のファイルは再起動時に削除されます。
  設定と学習した単語 (%LOCALAPPDATA%\KoEnJa) は残します。不要ならそのフォルダーを削除してください。

プライバシー
  入力した内容が PC の外に出ることはありません。インターネットに接続せず、何も送信しません。
