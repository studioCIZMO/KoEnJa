Grapheme cluster tables for the C++ and Kotlin ports' dropLastCharacter (UAX #29), currently from Unicode 16.0.0 (the version whose GraphemeBreakTest Swift's String on macOS matches): download GraphemeBreakProperty.txt and GraphemeBreakTest.txt (ucd/auxiliary/), emoji-data.txt (ucd/emoji/) and DerivedCoreProperties.txt (ucd/) from https://www.unicode.org/Public/16.0.0/ into one folder, run `python3 Android/tools/grapheme/generate.py <folder>`, and copy GraphemeBreakTest.txt to Android/engine/src/test/resources/ (both ports' tests read it).
