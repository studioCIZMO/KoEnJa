# iOS 1.0.7 (17) whatsNew — TestFlight 2026-11-23

## ko
키의 한글이 영문자와 같은 크기·굵기로 표시됩니다. 글자를 지우고 옆 키로 다시 친 교정(ㅏ → ⌫ → ㅣ)도 터치 위치 학습에 반영되어, 자주 빗나가는 키의 터치 범위가 쓰는 대로 맞춰집니다. 키 가장자리의 빈 공간(ㅣ·ㅏ 옆 등)도 그 키로 인식합니다. 지우고 다시 친 단어를 기억해 세 번째부터는 스페이스가 바로 고쳐 줍니다. 앱의 「오타 도움 → 오타 기록」에서 어떤 키가 어떻게 교정됐는지 보고 공유할 수 있습니다(이 기기에만 저장).

## ja
キーのハングルが英字と同じ大きさ・太さで表示されます。文字を消して隣のキーで打ち直した訂正（ㅏ → ⌫ → ㅣ）もタッチ位置の学習に反映され、よく外れるキーのタッチ範囲が使うほど合っていきます。キーの端の空きスペース（ㅣ・ㅏ の横など）もそのキーとして認識します。消して打ち直した単語を覚え、3回目からはスペースがすぐ直します。アプリの「ミスタイプの記録」で、どのキーがどう直されたかを見て共有できます（この端末にだけ保存）。

## en
The Hangul on each key is now as big and bold as the letter. Deleting a letter and retyping it on a neighboring key (ㅏ → ⌫ → ㅣ) now teaches the keyboard where you touch, so the keys you miss most often adapt as you type. The empty space beside the edge keys (next to ㅣ and ㅏ, for example) now counts as those keys. Words you delete and retype are remembered; from the third time, Space fixes them for you. The app's Typo log shows which keys were corrected how, and lets you share it (kept on this device only).
