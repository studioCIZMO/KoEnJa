## 한영일(KoEnJa) 0.3.13 — Araso 0.6.1 이후 엔진 (Mac)

- **전환 키로 고른 읽기 학습**: 단어를 치다가 전환 키로 읽기를 바꾸고 이어서 더 치면, 바꾼 그 글자들(so → 내)만 바로 학습하고, 이어 친 전체 단어(soon)는 학습하지 않습니다. 다음에 같은 글자를 치면 고른 대로 나오고, 더 긴 단어의 판단은 그대로입니다.
- **↑/↓ 키**: 전환 키로 띄운 읽기 목록은 커서가 그 단어 끝에 있을 때만 ↑/↓로 넘깁니다. 클릭으로 다른 곳에 간 뒤의 ↑/↓는 앱의 것입니다.
- **전각 스페이스**: 일본어 뒤의 전각 스페이스도 보통 스페이스처럼 단어 묶음을 끊습니다(그 뒤의 @가 이메일로 읽히지 않음).
- **앱별 단어**: 이 앱에서만 기억한 단어가 텍스트 단축어보다 먼저 옵니다.
- **Mac 앱**: 설정이 바뀌어 세션이 새로 만들어져도 vim 모드를 잊지 않습니다. 업데이트 확인에서 Mac 빌드가 없는 릴리스는 「최신」으로 처리하고 이전 기록을 지웁니다. 제거 시 복사본이 남으면 실패로 알립니다.
- 언어 판단(어떤 언어로 입력되는지)은 0.3.12와 같습니다.

**日本語**: 切り替えキーで読みを選んでから続けて打つと、選んだ部分（so → 내）だけをすぐ学習し、続けて打った単語全体（soon）は学習しません。↑/↓は、カーソルがその単語の末尾にあるときだけ読みの一覧を送ります。日本語の後の全角スペースも通常のスペースと同じく語のまとまりを区切ります。言語の判断は 0.3.12 と同じです。

**English**: Switch a word's reading, then keep typing: the pick is learned for the keys it was picked on (so → 내) right away, and the longer word (soon) isn't learned. ↑/↓ step the readings list only while the caret is at the word's end. A full-width space after Japanese ends the run like a normal space. Language detection is as in 0.3.12.
