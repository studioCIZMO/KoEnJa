- **Windows 0.3.5**: 0.3.4의 키 재전송이 1초 안의 같은 키를 재전송으로 오인하던 문제, 앱이 쓰기를 거절했을 때 키가 사라지던 문제, 같은 창에서 입력 칸이 바뀔 때 이전 조합이 남던 문제를 고쳤습니다. Caps Lock을 켜고 친 한국어(`RJATK` → `검사`)와 약어(`RST`)를 Mac과 같게 판단하고, `3ji` 같은 숫자 구절의 F9/F10에서 숫자가 사라지지 않습니다. 배운 단어와 한자 선택이 앱을 닫아도 남고(여러 앱이 함께 써도 안전), 비밀번호·비공개 칸에서는 학습과 진단 로그를 하지 않습니다.
