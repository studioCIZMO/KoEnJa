## 한영일(KoEnJa) 0.3.14 — Mac 설치 패키지, Windows 0.3.4

- **Mac 설치 패키지(`KoEnJa.pkg`)**: 받아서 열면 `/Library/Input Methods`에 설치하고 입력 소스에 등록합니다(이전 `~/Library` 복사본은 치웁니다). 설정과 학습한 단어는 그대로 남습니다. 터미널 설치(`get.sh`)와 `KoEnJa-Mac.zip`도 그대로 있습니다.
- **Mac 업데이트**: 설치된 복사본을 바로 교체할 수 없을 때(다른 계정이 설치했거나 macOS 앱 관리가 막을 때)는 「설치…」가 설치 패키지를 내려받아 CIZMO 서명·Apple 공증을 확인한 뒤 Installer로 엽니다(암호는 macOS가 묻습니다). 교체할 수 있는 복사본은 전처럼 암호 없이 바로 설치됩니다.
- **Mac 제거**: 설치 패키지로 설치한 복사본은 정보 탭 → 제거…가 설치 영수증까지 지웁니다. 완전 삭제 명령은 README의 「완전 삭제」에 있습니다.
- **Windows 0.3.4 — LINE 등에서 한글 뒤 Space/Enter가 안 들어가던 문제([#1](https://github.com/studioCIZMO/KoEnJa/issues/1))**: 한국어 단어를 치고 Space나 Enter를 누르면 단어만 확정되고 Space/Enter 자체는 앱에 전달되지 않던 문제를 고쳤습니다. 입력기가 TSF를 IMM32 호환 방식으로 쓰는 앱(LINE 등; 웹뷰·Chromium 앱은 영향 없음)에서 생겼습니다. 이제 단어를 넣은 뒤 그 키를 앱에 다시 보냅니다.
- 언어 판단(어떤 언어로 입력되는지)은 0.3.13과 같습니다. 엔진은 Araso 0.6.2와 같습니다.
- **Android 0.2.8**: 비밀번호·인증번호 칸에서는 단어 학습·추천·자동 고침을 하지 않습니다. 설정에 개인정보 안내와 처리방침 링크. (Google Play 반영은 별도)

**日本語**: Mac 用のインストールパッケージ（`KoEnJa.pkg`）を追加しました。入れ替えられないコピーは、アップデートの「インストール…」がパッケージをダウンロードして署名・公証を確認し、Installer で開きます。Windows 0.3.4 は、LINE などで韓国語の単語の後の Space/Enter がアプリに届かなかった問題（#1）を直しました。言語の判断は 0.3.13 と同じです。

**English**: A Mac installer package (`KoEnJa.pkg`). When the installed copy can't be replaced in place, Install… downloads the package, checks its signature and notarization and opens it in Installer. Windows 0.3.4 fixes Space/Enter after a Korean word not reaching apps such as LINE (#1). Language detection is as in 0.3.13.
