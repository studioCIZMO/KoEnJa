# iOS 1.0.6 whatsNew / Android 0.2.6 release notes

## ko
전환 키(한あA)로 단어의 읽기를 바꾸고 이어서 더 치면, 바꾼 그 글자들만 바로 학습하고 이어 친 긴 단어는 학습하지 않습니다. 일본어 뒤의 전각 스페이스도 단어 묶음을 끊습니다.

## ja
切り替えキー（한あA）で単語の読みを変えてから続けて打つと、変えた部分だけをすぐ学習し、続けて打った長い単語は学習しません。日本語の後の全角スペースも語のまとまりを区切ります。

## en
Switch a word's reading with the 한あA key, then keep typing: the pick is learned for the keys it was picked on right away, and the longer word isn't. A full-width space after Japanese ends the run like a normal space.
