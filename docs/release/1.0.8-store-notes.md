# iOS 1.0.8 (22) / Android 0.2.9 (12) whatsNew — 2026-11-25

iOS의 민감 칸 = password·newPassword·oneTimeCode·creditCardNumber(UITextContentType). Android의 민감 칸 = 비밀번호 inputType(텍스트/숫자/웹) 또는 IME_FLAG_NO_PERSONALIZED_LEARNING — 인증번호 칸은 앱이 그 표시를 달아야만 보호된다. 개인정보 안내·처리방침 링크는 Android 설정에만 있다(0.2.8).

## iOS

### ko
비밀번호·인증번호 칸에서는 단어 학습, 한자 변환 학습, 추천 단어, 자동 고침을 모두 하지 않습니다. 줄 끝 글자(ㅁ/a·ㅣ/l, z·m) 옆의 빈 공간을 눌러도 그 글자가 입력됩니다. 지우고 다시 친 단어의 교정을 더 정확히 기억하고, 오타 기록은 백업에서 제외되며, 설정 화면이 한국어로 나옵니다.

### ja
パスワード・認証コード欄では、単語の学習、漢字変換の学習、候補、自動修正をすべて行いません。行末のキー（a・l、z・m）の横の空きを押してもその文字が入ります。消して打ち直した単語の訂正をより正確に覚え、ミスタイプの記録はバックアップから除外され、設定画面が韓国語端末で韓国語になります。

### en
Password and one-time-code fields no longer teach the keyboard anything: no word learning, no kanji learning, no suggestions, no autocorrection. Tapping the empty space beside the key at the end of a row (a, l, z, m) types that key. Corrections you make by retyping are remembered more accurately, the typo log is excluded from backups, and Settings appear in Korean on Korean phones.

## Android

### ko
비밀번호 칸(과 학습 금지를 표시한 칸)에서는 단어 학습, 한자 변환 학습, 추천 단어, 자동 고침을 모두 하지 않습니다. 설정에 개인정보 안내와 처리방침 링크를 추가했습니다. 줄 끝 글자(ㅁ/a·ㅣ/l, z·m) 옆의 빈 공간을 눌러도 그 글자가 입력됩니다.

### ja
パスワード欄（と学習を禁じる指定のある欄）では、単語の学習、漢字変換の学習、候補、自動修正をすべて行いません。設定にプライバシーの説明とポリシーへのリンクを追加しました。行末のキー（a・l、z・m）の横の空きを押してもその文字が入ります。

### en
Password fields (and any field that asks keyboards not to learn) no longer teach the keyboard anything: no word learning, no kanji learning, no suggestions, no autocorrection. Settings gained a privacy note and a link to the policy. Tapping the empty space beside the key at the end of a row (a, l, z, m) types that key.
