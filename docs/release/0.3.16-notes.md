- **Mac 업데이트 뒤 입력 복구**: 업데이트로 입력기 프로세스가 바뀐 뒤 Slack·LINE처럼 그 전부터 입력 중이던 앱으로 돌아가면 글자가 들어가지 않고 입력 메뉴에 한영일 항목이 비어 보이는 문제. 새 복사본이 등록될 때(`KoEnJa --register`) 입력 소스를 다른 소스로 잠깐 바꿨다 되돌려 모든 앱이 새 프로세스와 다시 연결되게 했습니다(손으로 ABC ↔ 한영일을 바꾸던 것과 같은 동작). 손으로 복구하려면 `"/Library/Input Methods/KoEnJa.app/Contents/MacOS/KoEnJa" --reselect`.
- 0.3.15 → 0.3.16 업데이트에도 적용됩니다(옛 get.sh가 새 복사본의 `--register`를 실행하므로).

**日本語**: アップデートで入力メソッドのプロセスが入れ替わったあと、Slack や LINE など以前から入力していたアプリに戻ると文字が入らず入力メニューの項目も空になる問題を直しました。新しいコピーの登録時に入力ソースを一度切り替えて戻し、すべてのアプリが新しいプロセスにつなぎ直すようにしています。手動で復旧するには `KoEnJa --reselect`。言語の判断は 0.3.15 と同じです。

**English**: After an update replaced the input method's process, apps that had been typing through it (Slack, LINE) got no text and an empty input menu when you returned to them. Registering the new copy now switches the input source away and back, so every app reconnects to the new process. To recover by hand: `KoEnJa --reselect`. Language detection is as in 0.3.15.
