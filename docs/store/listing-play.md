## ko-KR

### 앱 이름
한영일 KoEnJa - 한영·일본어 자동 전환 키보드

### 간단한 설명
한영 전환 키 없이 한국어·영어·일본어를 자판 하나로. 로마자로 치면 언어를 알아서 고르는 다국어 키보드

### 자세한 설명
한영일(KoEnJa)은 한국어·영어·일본어를 QWERTY 자판 하나로 입력하는 다국어 키보드입니다. 한영 전환 키도, 일본어 키보드로 바꾸는 일도 없습니다. 친 글자를 보고 어떤 언어인지 단어마다 알아서 판단합니다.

예를 들어
• dkssudgktpdy → 안녕하세요
• hello → hello
• kyouhaiitenki → 今日はいい天気
• githubdp → github에 (영어 단어 + 한국어 조사)
• naver에서 kensaku → naver에서 検索

이런 분께
• 한국어·영어를 섞어 쓰며 한영 전환 키를 자주 잘못 누르는 분
• 일본어를 로마자로 입력하는 분, 한일 키보드를 오가는 분
• 한국어·일본어를 공부하거나 양쪽 언어로 메시지를 주고받는 분

주요 기능
• 자동 언어 전환: 한 문장 안에서 한국어, 영어, 일본어를 섞어 써도 단어마다 알맞은 언어로 들어갑니다.
• 한あA 키: 판단이 틀리면 방금 친 단어를 한 번에 다른 언어로 바꾸고, 고친 단어는 기억해 둡니다. 키를 두 번 누르면 세 번째 언어로 갑니다.
• 일본어 변환: 로마자로 치면 히라가나가 되고, 후보 막대에서 한자를 고릅니다. Mozc 사전 기반으로 다음 단어도 예측합니다.
• 우선 언어: 자주 쓰는 언어 순서(예: 한국어 > 일본어 > 영어)를 정하면 애매한 단어를 그 언어로 먼저 읽습니다.
• 오타 도움: 추천 단어, 이웃 키 후보, 자주 치는 위치를 배우는 터치 보정.
• 편의 기능: 위로 밀어 기호 입력, 스페이스를 밀어 커서 이동, 텍스트 단축어, 키보드 모양·색 설정. 설정 화면은 휴대폰 언어(한국어·일본어·영어)로 나옵니다.
• 가볍고 빠름: 변환 사전을 줄여 설치 용량이 작고, 입력 지연이 없습니다.

개인정보
입력한 내용은 모두 기기 안에서만 처리되고 어디로도 전송되지 않습니다. 앱에 네트워크 통신 기능이 없고, 광고와 분석 도구도 없습니다. 계정도 필요 없습니다.

오픈소스
언어 엔진은 오픈소스 Araso(MIT)를 바탕으로 하고, 소스 코드는 GitHub(studioCIZMO/KoEnJa)에 공개되어 있습니다. 같은 엔진의 Mac·Windows 입력기와 iPhone·iPad 키보드도 있어 어느 기기에서나 같은 방식으로 칩니다.

검색어: 한영 키보드, 한일 키보드, 일본어 키보드, 로마자 입력, 자동 언어 전환, 다국어 키보드, 한자 변환, 한국어 일본어 영어 키보드

## ja-JP

### アプリ名
KoEnJa - 韓国語・英語・日本語の自動切替キーボード

### 簡単な説明
切り替えキーなしで韓国語・英語・日本語をひとつのキーボードに。ローマ字で打つだけで言語を自動判別する多言語キーボード

### 詳しい説明
KoEnJa（한영일）は、韓国語・英語・日本語をひとつの QWERTY キーボードで入力する多言語キーボードです。言語切り替えキーを押す必要も、韓国語キーボードに持ち替える必要もありません。打った文字を見て、単語ごとにどの言語かを自動で判別します。

たとえば
• dkssudgktpdy → 안녕하세요
• hello → hello
• kyouhaiitenki → 今日はいい天気
• githubdp → github에（英単語＋韓国語の助詞）
• naver에서 kensaku → naver에서 検索

こんな方に
• 韓国語と日本語を混ぜて打つ方、韓国語キーボードと日本語キーボードを行き来している方
• 韓国語を勉強中で、ハングルをローマ字読みのまま打ちたい方
• 韓国の友人・同僚と両方の言語でやり取りする方

主な機能
• 自動言語切替：ひとつの文の中で韓国語・英語・日本語を混ぜても、単語ごとに正しい言語で入力されます。
• 한あA キー：判別が違ったら、打ったばかりの単語をワンタップで別の言語に切り替え。直した単語は記憶します。2回押すと3つ目の言語になります。
• 日本語変換：ローマ字で打つとひらがなになり、候補バーから漢字を選びます。Mozc 辞書ベースで次の単語も予測します。
• 優先言語：よく使う言語の順番（例：日本語 > 韓国語 > 英語）を決めると、あいまいな単語をその言語で先に読みます。
• 入力ミスの補助：おすすめ語、近いキーの候補、よく打つ位置を学習するタッチ補正。
• 便利機能：上フリックで記号、スペースをスライドしてカーソル移動、短縮入力、キーボードの形と色の設定。設定画面は端末の言語（日本語・韓国語・英語）で表示されます。
• 軽くて速い：変換辞書を絞ってあるのでインストール容量が小さく、入力の遅れがありません。

プライバシー
入力した内容はすべて端末内だけで処理され、どこにも送信されません。アプリに通信機能はなく、広告や解析ツールもありません。アカウントも不要です。

オープンソース
言語エンジンはオープンソースの Araso（MIT）をもとにしており、ソースコードは GitHub（studioCIZMO/KoEnJa）で公開しています。同じエンジンの Mac・Windows 版入力メソッドと iPhone・iPad 版キーボードもあり、どの端末でも同じ打ち方ができます。

キーワード：韓国語キーボード、ハングル入力、日本語 韓国語 キーボード、ローマ字入力、自動言語切替、多言語キーボード、漢字変換

## en-US

### App name
KoEnJa - Korean Japanese IME

### Short description
Korean, English, Japanese on one keyboard. It picks the language word by word

### Full description
KoEnJa (한영일) is a multilingual keyboard that types Korean, English and Japanese on a single QWERTY layout. No language-switch key, no swapping keyboards: it looks at what you typed and decides the language word by word.

For example
• dkssudgktpdy → 안녕하세요
• hello → hello
• kyouhaiitenki → 今日はいい天気
• githubdp → github에 (an English word with a Korean particle)
• naver에서 kensaku → naver에서 検索

Made for
• People who mix Korean and English and keep hitting the Korean/English toggle at the wrong time
• Japanese typists who use romaji and also write Korean
• Learners of Korean or Japanese, and anyone messaging friends or colleagues in both languages

Features
• Automatic language switching: mix Korean, English and Japanese in one sentence and each word goes in as the right language.
• The 한あA key: if a guess is wrong, one tap switches the word you just typed to another language, and the fix is remembered. Tap twice for the third language.
• Japanese conversion: romaji becomes hiragana, and you pick kanji from the candidate bar. Next-word prediction is built on the Mozc dictionary.
• Priority language: set the order you use most (for example Korean > Japanese > English) and ambiguous words are read in that language first.
• Typing help: word suggestions, nearby-key candidates and touch correction that learns where you tap.
• Comfort: swipe up for symbols, slide the space bar to move the cursor, text shortcuts, keyboard shape and colors. Settings follow your phone's language (English, Korean, Japanese).
• Light and fast: a trimmed conversion dictionary keeps the download small and typing instant.

Privacy
Everything you type stays on your device. The app has no network access, no ads, no analytics and needs no account.

Open source
The language engine is based on the open-source Araso (MIT) and the code is on GitHub (studioCIZMO/KoEnJa). The same engine powers KoEnJa for Mac and Windows and the iPhone/iPad keyboard, so you type the same way on every device.

Keywords: Korean keyboard, Japanese keyboard, hangul romanization, romaji input, automatic language switching, multilingual keyboard, kanji conversion, Korean Japanese English keyboard
